## Task 1
### What does the 3-letter acronym SMB stand for?

It stands for `Server Message Block` EternalBlue and WannaCry (2017) cases used this protocol

## Task 2
### What port does SMB use to operate at?

![Image](/assets/img/writeups/p3.png)

Heres how we can see which port uses `445` with a simple nmap scan on the IP

## Task 3
### What is the service name for port 445 that came up in our Nmap scan?

`microsoft-ds` appears right after the port in nmap

## Task 4
### What is the 'flag' or 'switch' that we can use with the smbclient utility to 'list' the available SMB shares on Dancing?

`-L` this in human language means: Enter the SMB service and ask for the list if theres one show it

## Task 5
### How many shares are there on Dancing?

There are `4` we can see it if we list it using
```shell
smbclient -L //<IP> -N
```

![Image](/assets/img/writeups/p4.png)

## Task 6
### What is the name of the share we are able to access in the end with a blank password?

Its `WorkShares` the others required admin passwords and IPC$ its most for processes comunications

## Task 7 
### What is the command we can use within the SMB shell to download the files we find?

Now we can login using 
```shell
smbclient //10.129.76.248/WorkShares -N
``` 
and `get` the flag.txt from James.P
