## Task 1
### How many TCP ports are open on the machine?

```shell
sudo nmap -p- -sS -sV --min-rate 5000 <IP>
```

![Image](/assets/img/writeups/p12.png)

We begin with a basic scan to scan all the open ports and as we can see we have `2` open ports

## Task 2
### Which service is running on port 27017 of the remote host?

As we saw before on the scan we have `MongoDB 3.6.8` which the version is included because we added -sV remember

## Task 3
### What type of database is MongoDB? (Choose: SQL or NoSQL)

`NoSQL` is uses JSON and not BSON, its more flexible and not as rigid as a SQL DB, they use diferent consult languages and its horizontal not vertical as a SQL DB

## Task 4
### What command is used to launch the interactive MongoDB shell from the terminal?

`mongosh` which stands for mongoDB Shell 

## Task 5
### What is the command used for listing all the databases present on the MongoDB server? (No need to include a trailing ;)

`show dbs` its the command to see the DBs

## Task 6
### What is the command used for listing out the collections in a database? (No need to include a trailing ;)

`show collections` or show tables aswell

## Task 7
### What command is used to dump the content of all the documents within the collection named flag?


`db.flag.find()` after switching with `use sensitive_information` we saw before
