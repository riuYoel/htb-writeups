## Task 1
### What does the 3-letter acronym FTP stand for?

It stands for `File Transfer Protocol`

## Task 2
### Which port does the FTP service listen on usually?

The port `21` is reserved for the FTP

## Task 3
### FTP sends data in the clear, without any encryption. What acronym is used for a later protocol designed to provide similar functionality to FTP but securely, as an extension of the SSH protocol?

Its `SFTP` this is not FTP with Secure protocol (FTPS) this uses only one connection, its secured and it has better auth

## Task 4
### What is the command we can use to send an ICMP echo request to test our connection to the target?

We talked about this in the Meow VM `ping`

## Task 5
### From your scans, what version is FTP running on the target?

![Image](assets/img/writeups/p2.png)

As we can see on the image after we login using ftp we can see the version `vsftpd 3.0.3`

## Task 6
### From your scans, what OS type is running on the target?

On the same image of task 5 we can see the answer Remote system type is `UNIX`
## Task 7 
### What is the command we need to run in order to display the 'ftp' client help menu?

For this one we just have to type `ftp -?` in order to display the client help menu

## Task 8
### What is username that is used over FTP when you want to log in without having an account?

As we previously saw, using `anonymous` we can access without any passwords in ftp

## Task 9 
### What is the response code we get for the FTP message 'Login successful'?

We can see it on the task 5 image aswell, `230` is the code after succesfully logging in

## Task 10
### There are a couple of commands we can use to list the files and directories available on the FTP server. One is dir. What is the other that is a common way to list files on a Linux system.

`ls` is the most common way to list files

## Task 11
### What is the command used to download the file we found on the FTP server?

Here we can use the command `get` to copy the file into our current directory

## Submit Single Flag 
### Submit the flag located on the FTP server.

After extracting the flag.txt we just have to use the `cat` command on it, so first leave the ftp server using `bye` and then read the flag
