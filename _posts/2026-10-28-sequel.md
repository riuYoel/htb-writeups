## Task 1
### During our scan, which port do we find serving MySQL?

```shell
sudo nmap -p- -sS -sV --min-rate 5000 <IP>
```

After the scan we can see the `3306` port open on MySQL

## Task 2
### What community-developed MySQL version is the target running?

```shell
ncat <IP> 3306
```

In return we will get a message with the version while trying to connect which is `MariaDB` i used this bc the nmap scan couldn't give me the version

## Task 3
### When using the MySQL command line client, what switch do we need to use in order to specify a login username?

`-u` from -username

## Task 4
### Which username allows us to log into this MariaDB instance without providing a password?

`root` its the default user if there's no configuration

So we can login using 
```shell
mariadb -h <IP> -u root --skip-ssl
```
