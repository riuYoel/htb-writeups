## 1. Pre-steps
Lets first connect to the IP and confirm everything works using `ping <IP>`

![Image](/assets/img/writeups/p1.png)

## 2. Recognition (Enumeration)
Once we connect to the VM IP Address and confirm its working we first began with an enumeration using `nmap <IP>`

![Image](/assets/img/writeups/p2.png)

## 3. Open ports
Here we confirm that theres an open port which is 23; telnet, with this information we can proceed and try logging in as root without a password using `telnet <IP>`

![Image](assets/img/writeups/p3.png)

## 4. Access
Here we can see it worked! now we are signed in with remote access as root, now the final step is getting the flag with `ls` and `cat`

![Image](assets/img/writeups/p4.png)

## 5. Done!
And thats it, we have the flag, see you in the next one!
