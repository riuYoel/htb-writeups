## Task 1
### Which TCP port is open on the machine?

![Image](/assets/img/writeups/p5.png)

```shell
nmap -p- -sS -sV --min-rate 5000 <IP>
```

As we saw on the picture if we do a basic nmap scan we can see the open port which is `6379`

## Task 2
### Which service is running on the port that is open on the machine?

Here with the same command it tells us the service `redis`

## Task 3
### What type of database is Redis? Choose from the following options: (i) In-memory Database, (ii) Traditional Database

`In-memory Database` why? because Redis instead of a classic db uses RAM to storage data, it has better latency due to this its used for big apps DBs such as GitHub, X, etc its also used as cache

## Task 4
### Which command-line utility is used to interact with the Redis server? Enter the program name you would enter into the terminal without any arguments.

`redis-cli` its the official tool on the cmd to comunicate directly with a redis server

## Task 5
### Which flag is used with the Redis command-line utility to specify the hostname?

`-h` means connect to the host (IP)

## Task 6
### Which flag is used with the Redis command-line utility to specify the hostname?

Once connected to Redis using
```shell
redis-cli -h <IP> -p <Port>
```
we can run the `info` command

## Task 7
### What is the version of the Redis server being used on the target machine?

![Image](/assets/img/writeups/p6.png)

After running the info command we can see the version if we scroll up `5.0.7`

## Task 8
### Which command is used to select the desired database in Redis?

Using `select`<n> we can move between DBs

## Task 9
### How many keys are present inside the database with index 0?

Here we can run 
```shell
dbinfo
```
After being sure we are in the correct db with `select 0`

## Task 10
### Which command is used to obtain all the keys in a database?

`keys *` is how we can see all the keys on the db
